# ユースケース

本プロジェクトは Han, Wu & Xiao (2023) の SABM — 2 つの LLM「企業」エージェントが差別化財ベルトラン複占の繰り返し価格ゲームを行う — を再現し，次のことができる:

1. **解析的な価格ベンチマークを計算する** (ベルトラン均衡 `p^B`・カルテル `p^M`)．任意の需要設定で，LLM なしに厳密に．[`benchmark`](cli.ja.md#benchmark--解析価格のみ-llm-不要即時) を参照．基本設定で `p^B = 6`, `p^M = 8`．
2. **LLM 駆動の価格ゲームを実行する**．会話がなくても価格がベルトラン均衡とカルテル価格の間に収束する**暗黙の共謀**を観測する．[`run`](cli.ja.md#run--llm-駆動の繰り返し価格ゲーム) を参照．
3. **製品差別化度 `d/β` と企業数をスイープ**し，collusion index の反応を見る．[`sweep`](cli.ja.md#sweep--dβ--企業数-感度分析) を参照．
4. **可視化する**: 価格軌跡 (ベルトラン/カルテル基準線つき)・collusion index 時系列，スイープ結果の折れ線/ヒートマップ．[可視化](visualization.ja.md) を参照．
5. **定性的に再現する**: 論文の核心的知見を再現する．解析ベンチマークは厳密．[再現](reproduction.ja.md) を参照．

## 典型的なワークフロー

**「競争価格・共謀価格のベンチマークは?」**
→ `cargo run --release -- benchmark …` → run の `metrics.csv` / `events.jsonl` を読む，または `uv run sabm-tools show-experiment-settings`．

**「2 つの LLM 企業は暗黙に共謀するか?」**
→ `cargo run --release -- run --firms 2 --persona active --max-rounds 1000 --seed 42` → `uv run sabm-tools visualize` → 価格が (ベルトラン, カルテル) 帯に収束し collusion index が約 0.5 に近づく様子を見る．

**「差別化は共謀にどう影響するか?」**
→ `cargo run --release -- sweep --d-beta-values 0.0,0.25,0.5,0.75,1.0 --firms-values 2,3 --runs 5` → `uv run sabm-tools visualize-sweep`．

**「LLM がない / CI 環境」**
→ `cargo run --release --example mock_smoke -- results`，または `run` / `sweep` に `--mock` を付ける．ライブ LLM 呼び出し 0 で同じ出力ファイルを書く．

各フラグは [CLI](cli.ja.md)，モデルと二層決定論は [アーキテクチャ](architecture.ja.md)，定量的目標は [再現](reproduction.ja.md) を参照．
