# Reproduction

Two levels of reproduction, matching the two-layer design.

## Analytic path — quantitatively exact

The Bertrand-equilibrium and cartel/monopoly prices are a pure, deterministic numeric computation (`analytic.rs`), independent of socsim and the LLM. For the paper's **basic setup** (`a = 14`, `β = 1/150`, `d = 1/300`, `α = 7/150`, `b = 1/30000`, `c_1 = c_2 = 2`, `d/β = 0.5`):

| Quantity | Paper | This implementation |
|----------|-------|---------------------|
| Bertrand equilibrium `p^B` | 6 | **6** (exact; `cargo test` asserts `|p^B − 6| < 1e-9`) |
| Cartel / monopoly `p^M` | 8 | **8** (exact; `cargo test` asserts `|p^M − 8| < 1e-9`) |

Verify in-sandbox (no LLM):

```bash
cargo run --release -- benchmark            # exact 1/150, 1/300 defaults → 6.000000 / 8.000000
cargo run --release -- benchmark --a 14 --beta 0.0066667 --d 0.0033333 --c1 2 --c2 2
```

(The rounded CLI inputs `0.0066667 / 0.0033333` give `p^B ≈ 6.00004`; the exact reciprocal defaults give precisely 6 and 8.)

## LLM-driven path — qualitative

Because the local default model (`llama3.2`) differs from the paper's `gpt-4-0314`, the LLM-driven tacit-collusion result is reproduced **qualitatively** (sign / trend), not to the paper's exact numbers.

| Condition | Metric | Paper | Reproduction target |
|-----------|--------|-------|---------------------|
| no communication, active | converged price | ≈ 7 (6 < 7 < 8) | inside (Bertrand, cartel); CI ∈ [0.3, 0.8] |
| no communication, active | rounds to stable | > 300 | order-of-magnitude (≫ communication case) |
| `d/β = 0` (independent) | converged price | monopoly 8 | ±0.5 |
| `d/β = 1` (homogeneous) | converged price | just above MC 2 | near (2, p^B] |
| asymmetric cost (`c_1=2, c_2=5`) | collusion | above equilibrium, below cartel | CI ∈ (0, 1) |

Run it (a real Ollama must be reachable):

```bash
export OLLAMA_MODEL=llama3.2:latest
cargo run --release -- run --firms 2 --persona active --communication false \
    --max-rounds 1000 --temperature 0 --seed 42
uv run sabm-tools visualize
```

With a small local model and a bounded round budget the tacit-collusion CI can be noisy; that is expected. The cache (`temperature=0` + fixed seed) makes reruns free and stable, so once a run is cached its trajectory is reproducible bit-for-bit on replay.
