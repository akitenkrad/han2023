# Use cases

This project reimplements Han, Wu & Xiao (2023)'s SABM — two LLM "firm" agents playing a repeated differentiated-goods Bertrand-duopoly pricing game — and lets you:

1. **Compute the analytic price benchmarks** (Bertrand equilibrium `p^B`, cartel `p^M`) for any demand setup, exactly, with no LLM. See [`benchmark`](cli.md#benchmark--analytic-prices-only-no-llm-instant). The basic setup gives `p^B = 6`, `p^M = 8`.
2. **Run the LLM-driven pricing game** and observe **tacit collusion** — the price settling between the Bertrand equilibrium and the cartel price even without communication. See [`run`](cli.md#run--llm-driven-repeated-pricing-game).
3. **Sweep product differentiation `d/β` and firm count** and see how the collusion index responds. See [`sweep`](cli.md#sweep--dβ--firm-count-sensitivity).
4. **Visualize** the price trajectory (with Bertrand/cartel reference lines) and the collusion-index time series, and the sweep results as line charts / heatmaps. See [Visualization](visualization.md).
5. **Reproduce qualitatively** the paper's headline finding; the analytic benchmarks are exact. See [Reproduction](reproduction.md).

## Typical workflows

**"What are the competitive and collusive price benchmarks?"**
→ `cargo run --release -- benchmark …` → read the run's `metrics.csv` / `events.jsonl`, or `uv run sabm-tools show-experiment-settings`.

**"Do two LLM firms tacitly collude?"**
→ `cargo run --release -- run --firms 2 --persona active --max-rounds 1000 --seed 42` → `uv run sabm-tools visualize` → look at the price trajectory settling inside the (Bertrand, cartel) band and the collusion index approaching ~0.5.

**"How does differentiation affect collusion?"**
→ `cargo run --release -- sweep --d-beta-values 0.0,0.25,0.5,0.75,1.0 --firms-values 2,3 --runs 5` → `uv run sabm-tools visualize-sweep`.

**"I have no LLM / I'm in CI."**
→ `cargo run --release --example mock_smoke -- results`, or add `--mock` to `run` / `sweep`. Everything writes the same output files with zero live LLM calls.

See [CLI](cli.md) for every flag, [Architecture](architecture.md) for the model and the two-layer determinism, and [Reproduction](reproduction.md) for the quantitative targets.
